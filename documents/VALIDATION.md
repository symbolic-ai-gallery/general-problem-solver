# 验证记录

遵照“不要过度测试”的要求，只执行核心算法检查和少量浏览器路径，不做完整浏览器矩阵或性能基准。

## 已完成

- 安装指定技术栈，使用 Volta / pnpm 版本声明和 pnpm 锁文件。
- TypeScript 严格检查与 Vite 生产构建通过，产物输出到 docs。
- 6 个 Vitest 测试通过：参考猴子五步计划与逐步前置条件、不可变输入、失败分支回滚、目标顺序与目标破坏、循环及搜索预算、合法空状态和 JSON 校验。其余成功案例在同一组测试内验证。
- 浏览器打开专业入口页并查看桌面暗色首屏。
- Chromium 模拟 390×844 视口，实验台无横向或纵向页面溢出；底部操作栏位于 y=781–844，五步计划列表可见。
- 浏览器实际求解猴子案例，得到 5 个计划操作和 26 条搜索事件；自动回放从初始状态推进到第 5 步，最终目标标记成立。

- 浏览器实际运行“目标顺序”案例，默认顺序未找到计划；在 JSON 编辑器中反转目标顺序后重新求解，得到“出示凭证领入场券 → 交出凭证换餐食”的两步计划。
- 手机编辑器合成可见视口高度 480px 时，操作栏底部为 467px，输入字号 16px；这不是软键盘真机测试。
- 桌面 1440×900 浅色实验台无页面溢出，底部操作栏位于视口底部。明暗切换已经检查。

- 最终构建产物在 `/docs/#/lab` 子路径成功加载 Worker 并得到猴子计划。
- 最后代码检查将回放完成标记改为具体步骤 ID，避免末步动画尚未结束时提前停止播放。此项修正执行了类型检查与生产构建，未再次扩大浏览器检查。

## 尚未测试

- iOS Safari / Android Chrome 真机的触控、地址栏、软键盘、安全区域和屏幕方向切换。
- 全部浏览器、全部菜单、导出下载和辅助功能组合；200% 放大及屏幕阅读器。
- 大型问题、长时间运行、低性能设备及 WebGL 上下文丢失／恢复。
- 原始 GPS 所有领域、IPL 运行兼容、最短计划和完备规划；本实现没有承诺这些能力。
- 线上发布和真实托管服务的缓存行为。

## 有限检查的含义

动画、布局和回放的浏览器检查不能替代现实物理验证或真机键盘检查。回归测试证明的是列出的目标栈算法行为，不代表可以解决所有被称为 GPS 的历史问题。
